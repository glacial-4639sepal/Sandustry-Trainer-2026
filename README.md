## 🔥 Project Overview

**This tool** is a comprehensive trainer for **Sandustry**. This trainer enhances Sandustry's single-player factory and exploration systems by providing easier access to resources, research, construction, production, and tool usage. It is designed around the game's mining, processing, logistics, physical reactions, and artifact exploration mechanics.

**Target Audience:** Suitable for players who want to experiment with factory layouts, test production chains, explore the destructible world, unlock technologies quickly, or reduce repetitive resource gathering in single-player sessions.

> **⚠️ IMPORTANT:** This tool is for **educational and private use only**. It does not modify any game files — all changes are temporary and reset when the game closes. The tool is **undetectable**, but **use it at your own risk**. Always back up your save files before use.

## 📖 Detailed Feature Guide

### Movement & Exploration

Launch the game first, load a save, then run the trainer with administrator permissions if required. Use the movement option to travel more quickly between surface facilities, mines, biomes, and underground locations. Disable the option when precise positioning is needed near machines or narrow passages.

### Tools & Inventory

Activate resource options after entering the game and opening the relevant inventory or storage interface. Selectively use unlimited resources for materials needed by construction and production chains, especially sand, water, gold, snow, seeds, and processed resources. Avoid enabling every resource option at once when testing a new save.

### World & Environment

Sandustry treats individual grains, flakes, seeds, spores, ice chips, liquids, and other materials as physical entities. Use the trainer to support large-scale excavation, factory construction, and artifact exploration while keeping important world interactions visible. Save before altering deep underground areas or using extensive construction options.

### Combat & Weapons

Sandustry is not centered on conventional combat. Fire, the flamethrower, and the rocket launcher are primarily used to alter terrain, clear obstacles, and access resources. Tool-related trainer options can make these activities faster, but they do not replace the game's production, exploration, and physical-reaction systems.
